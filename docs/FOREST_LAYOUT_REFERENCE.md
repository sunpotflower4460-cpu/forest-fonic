# 森の木の配置を観察する写真資料の使い方

『こころのえほん』の自然な森林空間をつくるための観察ノート。画像は `gallery/forest-layout.md`（収集後に自動生成）と `gallery/japan-landscape.md` を参照。

## 最初に見る順番

1. **俯瞰の密度** — `aerial-canopy-mosaic`, `aerial-forest-clusters`: 大きな樹冠と小さな樹冠、木の集団、林間の空間、草地との境界を観察する。
2. **中距離での幹の間隔** — `uneven-age-stands`, `giant-trees-and-saplings`: 太さも高さも違う幹、稚樹と大木が近接する場所、意外に開けている場所を確認する。
3. **光の空き地** — `canopy-gaps`, `natural-clearings`: 樹冠が途切れた場所に光が入り、若木や草本が生える様子を確認する。
4. **地形の影響** — `riparian-tree-corridors`, `slope-forest-spacing`, `ridge-tree-arrangement`: 川・谷・斜面・尾根ごとに木の並びと樹形がどう変わるかを見る。
5. **下草と時間** — `understory-patchiness`, `deadwood-and-fallen-trees`: 苔、枯枝、倒木、低木の斑を観察する。
6. **日本の生活圏** — `satoyama-woods`, `japanese-country-lanes`: 里山と民家の距離、道沿いの木、畑への境界で日常の空気感を守る。

## 制作時の原則

- **一様な乱数配置 = 自然ではない**。小さなまとまりと空白、樹種と樹齢の違い、地形と光の勾配がある。森の密度を1つの数値だけで決めない。
- ただし「自然林は必ず大木の周囲に空白がある」などの固定則にしない。陰樹、種子散布、更新、攪乱、森林管理によって例外がある。
- 上空の写真は樹冠の位置の参考であり、見えない幹の正確な位置や樹種を復元できるとは限らない。地上写真で補う。
- 森を作るなら、まず地形と水系→主木→低木と若木→道・空地→地表の素材と光の順に観察・生成を検討する。世界の適切さは実機の画面で検証する。
- `planted-vs-natural` で人工林の直線的な間隔と自然林の不規則な構造を分け、両方を日本らしい風景として使い分ける。
- 見かけの自然さだけでなく、遠景LODと低負荷描画、キャラクターの通路とカメラの見通しも守る。

## 写真の位置づけ

画像はあくまで制作の参考。正確な樹木間距離、種構成、樹齢、更新速度まで必要なら森林調査区データ・LiDAR・現地植生調査を別途参照する。ギャラリーの `visual_review: pending` は、写真の位置・構図・内容を人がまだ最終確認していない印。

ゲーム本体へ自動コピーはしない。利用する場合は設計者が、その場所に合う要素だけ絵本風3D表現へ翻訳する。
