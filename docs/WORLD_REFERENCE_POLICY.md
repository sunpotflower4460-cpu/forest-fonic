# 海外の街と自然の使い方 — 日本の空気感を中心に

## 表現の中心

『こころのえほん』の暮らしの基準は、日本の田舎、里山、身近な小川、畑、木造の家、素朴な小さな街の空気感。

既存の `forest`, `meadow`, `farm`, `town` と、新規 `japan-landscape` は、この中心世界を深める資料として優先する。

## 「海外参考」の意味

`world-town` と `world-nature` は、**別枠の参考ギャラリー**。海外の典型的な町並みをそのまま基本の街へ置き換えない。

特に学ぶもの：
- 家・屋根・窓・軒先の比率や素材の重なり
- 自然と暮らしの共存（店先の植物、路地と木陰、水辺の橋）
- 森の樹種差・林冠密度・林床の層
- 雲、霧、季節、気候ごとの光と空気色
- 地形に沿う街路や街と自然の接続

## 使う場所には自由がある

* **日常の家・町・牧場**：日本の身近な風景が優先。海外は窓辺の植物、石積み、屋根の質感など部分的な参考にする。
* **秘密の森・特別な土地**：遠い土地の植物や岩の造形を使ってもよい。ただし環境とのつながりを成立させる。
* **幻想世界・宇宙レストランなど**：異国の形や自然を積極的に発想源としてよい。

写真の収集先が海外でも、写真をそのまま貼るのではなく絵本風の色・形・柔らかな陰影に翻訳する。
