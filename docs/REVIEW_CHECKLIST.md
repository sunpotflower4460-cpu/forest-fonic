# 写真の目視レビュー

自動収集はライセンスの機械判定とファイル検証までです。各写真は制作に採用する前に次を確認します。

- [ ] 原典の Wikimedia Commons ファイルページを開き、現行の作者・ライセンス・出典と照合した
- [ ] `CREDITS.md` に作者・ライセンスURL・改変（縮小WebP）が記載されている
- [ ] 目立つ人物、商標、美術作品、写真内の独立した権利物について追加配慮の必要を判断した
- [ ] 写真が該当テーマ（森・水辺・牧場・町など）に実際に適合する
- [ ] 似た構図の写真ばかりに偏っていない
- [ ] 観察したい3D要素（輪郭・配置・地形・光・質感）が読み取れる
- [ ] 『こころのえほん』の絵本風世界観を守る解釈が可能
- [ ] 実装時はスマートフォンの描画負荷・視認性・季節切替を検証する

補足：直接ゲームに使う画像ではないため、`visual_review: pending` を「無条件のゲーム利用許可」と読み替えないこと。
