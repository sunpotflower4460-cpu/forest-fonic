# 画像ライセンスと収集方針

## 何を収録するか

- Wikimedia Commons のファイルページに、許可対象のライセンスが明示された写真。
- 許可対象：CC0、CC BY 2.0 / 3.0 / 4.0、CC BY-SA 2.0 / 3.0 / 4.0。
- 権利不明、写真以外のファイル、許諾条件を判別できないファイルは自動収集対象外。
- 「Public domain」とだけ記載された素材は法域や出典の違いを確認するまで自動収集しない。
- 自動選定の段階では、構図・人物・商標・撮影対象・著作権表示まで人の目で確認したわけではない。

## 出典表示

`catalog/CREDITS.md` は、画像ごとに **原典ページ・作者・ライセンス・変換したこと** を記載します。利用する際は、最新の原典ファイルページも確認してください。

CC0 でも作者と出典を残します。CC BY では作者・ライセンスへのリンク・改変の明示が必要です。CC BY-SA では、写真を改変した場合に追加条件が関係するため、ゲーム内のテクスチャや配布物への直接転用前に個別確認してください。

写真を WebP に縮小変換しています。画像データを編集しても、その画像のライセンスが消えるわけではありません。

## ゲームとの境界

1. このリポジトリの目的は**制作リファレンス**であり、『こころのえほん』への自動インポートは行いません。
2. 写真を観察して、独自の3D形状・シーン構成・色・光の表現を設計することを基本とします。
3. 元写真を直接テクスチャや宣材に使う場合は、該当画像のライセンス、クレジット、改変、肖像・商標等を別途確認します。
4. 自動収集された各画像は `visual_review: pending` のままです。目視レビューを完了して初めて制作判断に使います。
5. コード・ドキュメントのライセンスは、個々の写真の権利とは独立です。リポジトリを丸ごと CC0 や MIT とみなさないでください。

参照：[Wikimedia Commons — Reusing content outside Wikimedia](https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia)

## 運用上の境界

- 収集は手動または初回収集ブランチのプッシュ時のみで、定期実行はしません。
- ファイル上限・通信リトライ・受け入れるURLドメインを制限しています。
- 照合は `python scripts/collect_commons.py --verify` で実施します。
- 新たな資料の追加は PR で目視確認した後にマージします。
